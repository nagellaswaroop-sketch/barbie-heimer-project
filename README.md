# Multi-Robot Task Negotiation Engine

A multi-robot warehouse simulation that enables robots to negotiate and coordinate task assignments in a high-density warehouse environment.

## Features

- Multi-robot task allocation
- Task negotiation between robots
- Collision avoidance
- Pathfinding
- Deadlock detection
- Warehouse simulation
- Live web dashboard
- Backend API
- Configurable number of robots and tasks

## Architecture

```text
Tasks
  ↓
Task Negotiation
  ↓
Robot Assignment
  ↓
Pathfinding
  ↓
Collision Detection
  ↓
Robot Movement
  ↓
Task Completion
  ↓
Live Dashboard
